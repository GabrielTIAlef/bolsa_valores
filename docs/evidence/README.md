# Evidências sintéticas

Arquivos selecionados de uma geração confirmada de `bolsa.synthetic.generate(seed=42)` e de duas validações locais. Não são registros de contas, cotações ou operações reais.

validacao.json contém cobertura, metadados fictícios, versões, hash da entrada e reconciliação SQL/Python. resumo_ativos.csv e narrativa.txt descrevem somente essa janela artificial. PNGs mostram os indicadores da mesma geração. O SQLite não é versionado; é reconstruído e testado pela demonstração.

tests-result.json e notebook-result.json são registros locais. instalacoes.json distingue as duas instalações. O resultado do GitHub Actions só pode ser declarado após execução remota real.
